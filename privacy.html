Privacy policy

Pragma YT Helper. Last updated: 8 October 2026.

Who this applies to

Pragma YT Helper is a private tool. Its only user is the owner of the Pragma YouTube channel, who uses it to manage that channel.

What data it accesses

With the permissions granted through Google sign-in, the tool accesses the owner's own YouTube channel: it uploads and schedules videos, sets thumbnails and captions, and reads the channel's statistics through the YouTube Analytics API. It does not access data of any other person.

Where the data stays

The sign-in tokens and any data the tool reads are stored only on the owner's computer. Nothing is sold, shared with third parties, or used for advertising.

Revoking access

Access can be revoked at any time from the Google account security settings: myaccount.google.com/permissions.

Google and YouTube terms

This tool uses YouTube API Services. By using it you are bound by the YouTube Terms of Service, and Google handles data according to the Google Privacy Policy.

Contact

Questions about this policy: through the GitHub profile of the owner.
