Pragma YT Helper.

Pragma YT Helper is a private tool used by Luca Tomasino to manage his own YouTube channel, Pragma. It runs on his computer and is not offered to anyone else.

What it does

It uses the YouTube Data API and the YouTube Analytics API to upload videos to the Pragma channel, schedule them, set their thumbnails and captions, and read the channel's own statistics.

Who can use it

Only the owner of the Pragma channel. There is no sign-up and no public access.

Privacy policy
